# Agent Note: 面向下游管理的原生 V4 扩展

Status: implemented

[English](2026-10-03-native-v4-downstream-management.md) | 中文

## 问题

下游 Product 管理器需要跨普通 Session API、Agent 创建、持久化与浏览器视图保持精确资源归属和准入。官方 DSH 0.2.0-rc.2 提供原生 V4 执行，但缺少消费方需要的部分公开约定。替换原生生命周期实现会丢失上游行为，也无法清晰记录部署实际执行的差异。

## 决策

fork 保留官方 V4 Session 与 Agent 生命周期实现，并增加有界公开扩展。创建中间件在 teardown 前拥有已接纳工作；空闲与删除 reservation 排除并发工作；发布检查拒绝陈旧创建或派生状态写入。持久化删除提交后才使缓存、查询和 Workspace 失效。可恢复 fork 保留调用方预留身份、目录与精确闭合前缀，包括空前缀；普通原生事件截点保持其既定行为。

有效执行目录是归属精确 Session 的持久事实，与不可变创建 cwd 分离。目录消费方使用公开解析器。标题策略与生成状态归分支；公开计量助手允许 Product 在原生辅助执行上选择摘要。原生 V4 验证这些 required 扩展事件。自定义升级前 reader 和坐标迁移扩展不保留；下游启动独立原生 V4 generation，旧数据保持不活动。

提示词准备在 provider 与 schema 前完成等待。部署约束覆盖已解析策略和批准后的升权。可信执行环境贡献与模型 Tool 输入、进程环境分离。Gateway 策略覆盖查找和调用；通道级回环权限补充浏览器认证。父级投递策略保留已接纳内容并控制唤醒，消息保留父级 Turn 归属。

浏览器库导出可加载而不激活默认插件。页面协调会装载库导出，但只为活动插件行创建 Loader fiber；将行切回库时会释放其插件生命周期。Conversation decorator 保留分组与发布钩子；逻辑 Chat 导航和统计可排除已退出展示的轮次。本地 Markdown 链接解析归调用方。模型目录分别暴露已注册执行提供方与可用目录组。

PiAi bridge 将已解析历史 Tool addition 映射到 transcript system 消息，仅对显式支持协议／模型标志的路由提供原生增量能力。准备好的快照绑定能力与派发。不支持路由保持原生兼容投影；远程网关仍需实际协议验证。

## 考虑过的替代方案

**将原生服务复制到下游包。** 这会为执行、持久化或 transport 创建竞争权威。通用缺失约定属于当前原生所属模块。

**原样覆盖旧 fork 字节。** 旧接口与消息表示不能描述原生 V4。必要行为集成到当前实现，旧兼容专用代码退出。

**将可见 schema 视为授权。** 直接和其他执行路径能绕过展示。工具被延迟或搜索时，作用域查找、guard 和策略仍是权威。

**通过自定义迁移保持旧日志。** 下游发布明确排除旧 Session 导入。当前 V4 持久化与回放独立验证；旧数据保留，不抹除或静默重绑定。

## 后果

下游管理可消费公开执行与资源约定，无需拥有 DSH 核心状态。成本是精确源码差异与原子 fork 产物安装。原生系统锁、删除／fork 竞态测试、作用域策略测试和 Client 库测试覆盖当前行为。Host 编译与本地 SDK payload 测试验证当前类型和序列化路径。远程提供方支持与 Product Web/Desktop 验收仍需独立证据；本记录不声称下游流程通过。

失败的 TypeScript project 不生成产物，防止不完整构建把可执行文件留在源码旁。源码测试解析单一模块身份，不混用生成 JavaScript 与 TypeScript 注册。

机器可读的 fork 清单记录下游绑定所需的精确官方提交；维护中的正文引用发布 tag。引用校验只允许该结构化提交字段，其他引用仍遵循正文规则。
