# Agent Note: Profile 插件快照与部署拥有的行策略

Status: implemented

[English](2026-10-08-profile-plugin-snapshot-and-deployment-policy.md) | 中文

## 问题

组合包选择、声明的行与 Loader 状态描述不同事实。独立读取可能将新选择与旧运行条目拼在一起，失效读取也可能覆盖更新的视图。部署还需要保留产品壳与管理组件，同时允许选择可选组合包；仅禁用开关无法约束直接服务调用。

## 决策

[Host 管理器](../../../../packages/boot/plugin-manager/README.zh.md)通过 `snapshot()` 提供一次组合包与插件的共同观测。它先取得现有 profile manifest 写入锁，再进入 HMR（热模块替换）队列，并等待清单工作结束后才释放二者。此机制扩展[当前 profile 事务的所有者](2026-09-14-current-profile-plugin-management.zh.md)，不增加独立安装器或同步服务。原有列表方法仍可用。快照序列化覆盖遵守协调规则的 profile 修改与 HMR 重载；它不锁住任意编辑器，也不使 fiber 阶段固定不变。

[Client 管理器](../../../../packages/client/ui-plugin-manager/README.zh.md)消费该快照。读取期间发生失效通知时，它丢弃整轮结果并重新读取，已接受的卡片保持可见。修改操作在最后一次刷新尝试结束前保留忙碌键。传输失败结束为可重试的错误状态，dispose（资源释放）阻止晚到结果发布。[侧栏与安装请求的所有者](2026-09-09-plugin-management-in-the-web-sidebar.zh.md)保持有效。

`managedRows` 默认为空字典。每条规则指定一个精确的组合行 id 和模块、所需启用状态，以及可选的替代模块展示信息。运行启用与阶段保持为观测值；`deploymentPolicy` 不会用所需值替换它们。模块不匹配时不会套用规则。策略不安装包、不改写启动选择，也不重新激活可选组合包。

Host 拒绝违背匹配规则的管理请求。修复到指定状态仍要求唯一且可定位的 Include 行；管理后端保护优先于部署配置。明确支持的管理 UI 替代允许要求该 UI 行保持禁用，同时保留管理后端。组合包选择在保存前，结合当前用户、home 与调用覆盖层检查候选组合。它拒绝改变受保护行的模块或有效启用状态，包括禁用祖先 group，也拒绝删除或修改当前管理器的策略声明。无法解析且发生变化的条件按拒绝处理；无关的可选层仍可选择。

## 考虑过的替代方案

**拼接独立的列表响应。** Client 读取计数可以丢弃旧响应，却无法使两次 Host 观测属于同一 profile 代次。一次序列化的 Host 操作提供缺失的关联。

**仅在页面禁用控件。** 直接 Remote 与工具调用可以绕过禁用开关。管理器负责拒绝，页面展示返回的原因。

**保护所有已安装插件或在启动时强制默认值。** 这会取消合法的可选配置，并以所需值遮蔽已保存的配置。精确部署规则只保护指定行，保留实际状态的可见性。

## 后果

Host 与 Client 的快照消费方一起发布。读取可能等待包操作或 HMR 工作。管理器控制的修改在保存前保持部署规则；操作者编写的配置拥有独立权限，不由策略统一改写。管理器不额外持久化投影，也不改变 Session 格式或模型请求构造。

## 验证

Host 回归覆盖异步清单期间的 profile 锁与 HMR 队列、指定状态修复、歧义目标、模块不匹配、可选层、祖先 group 禁用，以及清除管理器策略的尝试。Client 回归覆盖失效快照、修改后刷新、传输失败、dispose，以及实际状态与所需状态的独立性。浏览器组件 fixture（测试前置数据）验证替代标识与不可用控件，不证明外部插件兼容性。
